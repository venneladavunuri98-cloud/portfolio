# Vennela Davunuri — Automation Developer Portfolio

A dark, Swiss-inspired portfolio site showcasing automation and AI systems — built with Next.js, TypeScript, and Tailwind CSS.

**Live site:** [portfolio-vennela3.vercel.app](https://portfolio-vennela3.vercel.app)

---

## About

I'm an automation developer building production-grade AI systems — n8n workflows, agentic RAG pipelines, voice AI agents, and lead generation engines that replace manual work with reliable, self-running infrastructure.

## Sections

- **Hero** — Introduction and rotating focus areas
- **About** — Background, tech stack tags, and impact stats
- **Services** — What I build: AI voice systems, workflow automation, RAG, CRM automation, lead gen, and strategy consulting
- **Case Studies** — Real projects with technical build breakdowns and hover-to-reveal proof-of-work screenshots from actual n8n workflows
- **Process** — How I work, from discovery to handoff
- **Skills** — The tools I use: n8n, Vapi, Supabase, OpenAI, Claude, PostgreSQL, Apollo.io, LangChain, Meta APIs, and more
- **Contact** — Get in touch

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Motion (Framer Motion successor)
- **3D:** React Three Fiber / Three.js
- **Icons:** Tabler Icons

## Running Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deployment

This project is deployed on [Vercel](https://vercel.com). Any push to the `main` branch automatically triggers a new production deployment.
